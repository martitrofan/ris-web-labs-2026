## Как пользоваться

1. Откройте лабораторную в меню слева.
2. На паре работайте по **методичке**.
3. **Карточку** читайте, если нужна теория простыми словами.
4. **Шаблоны** скопируйте в свой учебный репозиторий (`/docs/…`).

Пройденные работы остаются в каталоге — к ним можно вернуться в любой момент.
