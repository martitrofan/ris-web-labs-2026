# Как устроен каталог (для преподавателя)

Студентам эта страница не обязательна.

## Добавить следующую лабораторную

1. Скопируйте папку `docs/labs/01/` → `docs/labs/NN/`.
2. Положите туда: `README.md` (обзор), `method.md`, `lab.md`, нужные файлы в `templates/`.
3. Добавьте запись в `docs/labs.json`:

```json
{
  "id": "02",
  "number": 2,
  "title": "Архитектура и модель данных",
  "published": true,
  "unlocked": true,
  "unlockCode": null,
  "sidebar": [
    { "path": "labs/02/", "label": "Обзор ЛР2" },
    { "path": "labs/02/method", "label": "Методичка" },
    { "path": "labs/02/lab", "label": "Карточка (теория)" }
  ]
}
```

4. Закоммитьте и сделайте `git push` — GitHub Pages обновится за минуту-две.

## Вариант с кодом на паре

Если файлы уже в репозитории, но открывать рано:

```json
"published": true,
"unlocked": false,
"unlockCode": "lab02-secret"
```

На паре сообщите код. Студент вводит его один раз — доступ остаётся в этом браузере до закрытия вкладки/сессии.

Пока материала нет в репо — проще просто **не публиковать** запись (`published: false` или нет папки). Тогда «открытие следующей лабы» = обычный push с новыми файлами.
