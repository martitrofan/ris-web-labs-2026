# Лабораторная работа (ЛР) 13. Предзащита


**Студенту на пару:** работать по [методичке](/labs/13/method) — шаги, Git и чеклист сдачи. Эту карточку читать, если нужна теория простыми словами.

4 ч. Тема лекции 17. Лекцию слушать не обязательно. После ЛР12. Закрывает текущий контроль (ТК) 4.


## Зачем эта работа

Это не «ещё одна фича». Это репетиция защиты курсовой. Новую подсистему (чат, карту, мобильное приложение) писать нельзя. Чините то, что ломает запуск и три критерия из ЛР1, проводите демо на таймере, оформляете отчёт.

Если ЛР12 не стартует — вся пара на запуск. Это сдача с долгом, не день новых идей.

## Цель

Стенд принимают. Демо 7 минут. Записка начинает ссылаться на живые папки, не на обещания.

## Что сдать

| Артефакт | Зачем |
|----------|--------|
| Список дефектов | Шаги, ждали, было, что сделали |
| Повтор трёх критериев ЛР1 | После правок они снова зелёные |
| Демо 7 минут + вопросы | Как на курсовой |
| Итоговый отчёт | Цель семестра, ссылки на `/docs`, `/frontend`, `/backend`, `/db`, что не вошло и почему |

Мелкая доработка — только с согласия преподавателя и только одна. «Заодно переписать весь UI» — нет.

## Теория на пару

25–30 минут, остальное — стенд и репетиция. Если лекцию 17 не слышали, этого блока хватит.

### В каком порядке чинить

1. Не запускается у соседа.
2. Ломается критерий ЛР1 (не создаётся, не назначается, не идёт в работу).
3. Кривые коды (500 вместо 404) и дырявые права (403 нет).
4. Цвет кнопок, отступы, «некрасиво».

После каждого пункта снова прогоните **затронутый критерий целиком**, не только «ту кнопку». Часто чинят одно и ломают список.

### Демо на 7 минут — что говорить

Стенд поднять **до** того, как вас вызвали. Не начинать с «сейчас поставлю Node».

Минутный план:

1. **30 секунд.** Кто заказчик, какой один критерий сейчас покажете.
2. **4 минуты.** Один id: форма → Network (тыкаете код 201 и id) → строка в PostgreSQL → назначение → статус `InProgress`.
3. **2 минуты.** Выйти / без токена — создание даёт 401. Рестарт API — запись на месте.
4. **Остаток.** Вопросы. Если время вышло — остановитесь сами, не договаривайте архитектуру вселенной.

Уложились в 5 минут — хорошо. Ушли на 12 — режьте слова, не добавляйте экраны.

Не делать: листать все файлы проекта «вот контроллер, вот ещё контроллер». Комиссия не успевает.

### Откуда берётся записка курсовой

Записка **ссылается** на файлы, не копирует код на десять страниц.

| Глава записки | Уже лежит здесь |
|---------------|-----------------|
| Анализ | ЛР1 |
| Модель | ЛР2 |
| Экраны | ЛР3–6 и 12 |
| API | ЛР8 |
| SQL | ЛР9 |
| Миграции | ЛР10 |
| Вход | ЛР11 |
| Дефекты и «что не делали» | ЛР12–13 |

«Что не вошло» берут из списка расширений под диплом, который писали в заявке на тему. Это не стыдно. Стыдно обещать в записке то, чего нет в репозитории.

### Вопросы, которые зададут даже без лекции

Отвечать своими словами, потом ткнуть в экран или файл.

- Чем информационная система не сайт кафедры?
- Почему браузер не подключается к PostgreSQL сам?
- Зачем два разных PATCH, а не одна «сохранить заявку»?
- Почему название участка не пишут в каждой заявке?
- Почему пароль не кодируют Base64?
- Что сознательно не сделали и зачем это в списке на диплом?

Полный банк к экзамену: список вопросов к экзамену (выдаёт преподаватель). Сегодня не зубрить все 34, хватит шести.

## Порядок на 4 часа

1. Сосед запускает ваш проект по README. Всё, где он застрял — дефект запуска, чинить первым.
2. Предзащита по чек-листу ЛР12, записать дыры.
3. Чинить запуск и критерии. После пункта — снова критерий.
4. Если время есть и преподаватель кивнул — одна мелкая доработка.
5. Репетиция 7 минут с таймером телефона. Сосед задаёт три вопроса из списка выше. Не подсказывать себе.
6. Отчёт и правка README, если команды запуска изменились.

## Сдача

Сосед поднял стенд. Три критерия снова выполняются. Демо влезает в 7 минут. На защите: какой дефект ломал сдачу и чем доказали, что закрыт (повторный прогон, не «ну вроде починили»); одно требование ЛР1 видно на экране, в запросе и в таблице.

## Частые ошибки

- Начинают демо с проводника файлов.
- Чинят баг и не повторяют сценарий — баг «вернулся».
- Добавляют чат и не успевают показать создание.
- Стенд поднимают при комиссии — полдемо уходит на `npm install`.
- В отчёте «всё сделано», в README сосед не проходит шаг 2.
- Три критерия «на словах», без id в UI / Network / SQL.
- Тратят пару на новый экран вместо починки запуска.
