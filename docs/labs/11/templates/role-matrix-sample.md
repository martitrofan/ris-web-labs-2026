# Образец матрицы ролей (ЛР11)

Скопировать в свой репозиторий как `/docs/role-matrix.md` и **подставить свои роли** из таблицы соответствия ЛР1. Ниже — заполненный пример курса (заявки энергопредприятия).

Связь: [`../11-безопасность.md`](../11-безопасность.md).

## Учебные учётки (пример)

| Логин | Роль | Пароль (учебный, в README можно) |
|-------|------|----------------------------------|
| `dispatcher` | диспетчер (создаёт, назначает) | `Passw0rd!` |
| `engineer` | инженер (меняет статус **своих**) | `Passw0rd!` |

Пароли в PostgreSQL хранятся **hash**, не этот текст. В Git — только учебные логины, не строка подключения БД.

## Матрица «роль × действие»

| Действие | Диспетчер | Инженер | Гость (не вошёл) |
|----------|-----------|---------|------------------|
| `POST` создать объект | да → 201 | нет → 403 | нет → 401 |
| `PATCH …/assignee` назначить | да | нет → 403 | нет → 401 |
| `PATCH …/status` в работу | нет* | да, **если** он assignee | нет → 401 |
| `PATCH …/status` чужой записи | — | нет → 403 | нет → 401 |
| `GET` список | да | да (или только свои — как в ТЗ) | нет → 401 |

\* Если в ТЗ диспетчер тоже закрывает — напишите явно; иначе исполнитель двигает статус.

## Доказательства на сдаче

| Проверка | Ожидание | Где смотреть |
|----------|----------|--------------|
| POST без входа | 401 | Swagger / Network |
| Инженер → статус чужой заявки | 403 | Swagger |
| Описание со `<script>…` | текст на экране, не `alert` | Vue UI |
| Столбец пароля в БД | hash, не `Passw0rd!` | pgAdmin |

## Чем не копия соседа

В вашей матрице — **ваши** имена ролей и путей API из ЛР1/ЛР2. Смысл строк тот же.
