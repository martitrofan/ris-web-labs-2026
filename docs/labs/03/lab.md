## Зачем эта работа

Вы уже умеете HTML и CSS. Сегодня не «ещё одна вёрстка», а заготовка программы: три экрана, которые потом начнут жить данными. Сервера нет, сохранения в базу нет. Нужно, чтобы сосед по README открыл те же экраны у себя.

Vue — это как шаблон объявления: места «тема» и «статус» заполняются из списка. Поменяли список — объявления перерисовались сами. Если сделать три отдельных HTML-файла, список придётся копировать руками.

## Цель

Поднять Vue-приложение и нарисовать три экрана. Кнопки могут ещё ничего не сохранять.

## Что сдать

Папка `/frontend` **в том же** репозитории, где лежат `/docs`.

- Vue 3 + Vite, язык JavaScript, не TypeScript;
- команда `npm run dev` открывает интерфейс в браузере;
- экраны: список, форма создания, вход;
- в разметке есть `main`, таблица или список, `form`, `label` (не одни `div`);
- имена полей как в ЛР2: `title`, `siteId`, `description` — или ваши из таблицы соответствия.

Красоту не оценивают. Оценивают: видно смысл, имена совпали, сосед запустил.

Папку `node_modules` в Git не кладут: это скачанные библиотеки, их заново ставит `npm install`.

Нужен Node.js версии LTS (долгосрочная поддержка). В терминале:

```bash
node -v
npm -v
```

Если команд нет — сначала поставить Node.js, не начинать проект.

Файл `.vue` нельзя открыть двойным щелчком как `index.html`. Браузер его не понимает. Его собирает Vite.

### Что такое Vue и Vite

**Vue** — библиотека для экранов. Вы описываете: «вот массив заявок, вот таблица». Vue сам рисует строки.

**Vite** — программа, которая запускает проект. Команда `npm run dev` поднимает сайт на порту **5173**. Это тот «клиент» со схемы ЛР2. В адресной строке будет что-то вроде `http://localhost:5173`.

**Однофайловый компонент (SFC)** — один файл `.vue` из трёх частей:

```vue
<template>
  <!-- что видно -->
</template>

<script setup>
  // данные и функции
</script>

<style scoped>
  /* стили только этого куска */
</style>
```

Слово `scoped` значит: стили не разъедутся на чужие экраны.

### Три директивы, которые нужны сегодня

**`v-for`** — повторить кусок разметки по массиву. Как цикл, только в HTML.

```html
<tr v-for="item in items" :key="item.id">
  <td>{{ item.number }}</td>
  <td>{{ item.title }}</td>
  <td>{{ item.status }}</td>
</tr>
```

`:key="item.id"` помогает Vue понять, какая строка какая. Без ключа список может странно мигать.

**`{{ item.title }}`** — подставить текст. Именно текст, не HTML. Если в теме написали `<b>важно</b>`, на экране будут символы угловых скобок, и это правильно.

**`v-if`** — показать блок или не показать. Сегодня так переключают три экрана (пока нет адресов `/new`).

### Три разных «id», их путают все

| Что | Зачем |
|-----|--------|
| `id` у `<input>` | Чтобы `label` знал, к какому полю подпись |
| `id` записи | Технический номер будущей заявки в базе |
| `number` | Что говорят люди: «заявка 104» |

На форме подпишите текстом: тема 5–80 символов, описание 10–500. Саму проверку напишете в ЛР5.

Не ставить: TypeScript, Pinia, axios. Лишнее, курс их не спрашивает.

const items = [

## Порядок на 4 часа

1. Node.js стоит, `node -v` печатает номер.
2. В **корне** репозитория (рядом с `docs`, не внутри `docs`):

   ```bash
   npm create vue@latest frontend
   ```

   Мастер спросит опции. Ответы: **не** TypeScript, **не** JSX, **не** Pinia, **не** тесты. Роутер можно пропустить — поставите в ЛР4.

3. Дальше:

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

   Должна открыться заготовка Vite. Если порт занят — в терминале Vite напишет другой, в README тогда укажите его. По умолчанию ждём 5173.

4. Откройте `src/App.vue`. Вместо приветствия Vite — ваш массив и три экрана.
5. **Список:** номер, участок (пока числом, имя участка позже), тема, статус.
6. **Форма:** три поля с `label`. Кнопка «Создать» может пока ничего не делать.
7. **Вход:** логин и пароль, без настоящей проверки. Это заготовка экрана.
8. Три кнопки вверху: «Список», «Создать», «Вход». По `v-if` показывают один экран.
9. В `.gitignore` (корня или `frontend`) строка `node_modules`. В корне репозитория README:

   ```
   Нужен Node.js LTS.
   cd frontend
   npm install
   npm run dev
   Открыть адрес, который напишет терминал (обычно http://localhost:5173).
   ```

10. Коммит без `node_modules`. В отчёт — три скрина и одна строка: «критерий 1 ЛР1 закрывают поля …».

## Чеклист семантики и доступности (сдать вместе с экранами)

Отметить да/нет. Один «нет» — доработать до защиты ЛР3.

| № | Проверка | да/нет |
|---|----------|--------|
| 1 | Есть `<main>` (или один главный контейнер с понятной ролью) на рабочих экранах | |
| 2 | Форма создания обёрнута в `<form>` | |
| 3 | У каждого поля есть `<label>` (через обёртку или `for`/`id`) | |
| 4 | Список — `<table>` или осмысленный список, не только безликие `div` | |
| 5 | При открытии формы фокус на первом поле (можно `autofocus` на теме) | |
| 6 | Стили в `scoped` (или аккуратно локально); макет читаемый | |
| 7 | Оценку за «красивый дизайн» не ждут — поля и статусы читаются | |

CSS свой, как умеете. Отдельную лабу по вёрстке курс не ставит: семантика закрывает темы 2.1–2.2 РПД внутри Vue.

### Мини-заготовка `App.vue` (идея, не копировать слепо)

Три экрана через `v-if`, пока нет vue-router (роутер — ЛР4):

```vue
<script setup>
import { ref } from 'vue'
const screen = ref('list') // 'list' | 'new' | 'login'
const items = ref([
  { id: 1, number: 'A-101', title: 'Насос не запускается', siteId: 2, status: 'New' }
])
</script>

<template>
  <div>
    <header>
      <button type="button" @click="screen = 'list'">Список</button>
      <button type="button" @click="screen = 'new'">Создать</button>
      <button type="button" @click="screen = 'login'">Вход</button>
    </header>

    <main v-if="screen === 'list'">
      <!-- таблица / v-for -->
    </main>

    <main v-else-if="screen === 'new'">
      <form @submit.prevent>
        <label>Тема <input name="title" autofocus /></label>
        <label>Участок <input name="siteId" /></label>
        <label>Описание <textarea name="description"></textarea></label>
        <button type="submit">Создать</button>
      </form>
    </main>

    <main v-else>
      <!-- заглушка входа -->
    </main>
  </div>
</template>
```

Имена полей замените на свои из таблицы соответствия, смысл тот же.

## Сдача

Сосед на чистой машине ставит `npm install` и видит три экрана. Имена полей как в ЛР2. Чеклист семантики заполнен. На защите своими словами: зачем Vite, если HTML уже умеете; чем `v-for` лучше трёх строк, написанных руками; какой порт у клиента на схеме ЛР2; зачем `label`, если подпись можно написать текстом рядом.

## Частые ошибки

- Проект создали в другой папке, не в репозитории курса.
- Открыли `App.vue` двойным щелчком — белый экран.
- Закоммитили `node_modules` — репозиторий распух, сосед всё равно ставит заново.
- Поля `name`, `text`, `place` — на ЛР8 начнётся путаница с сервером.
- TypeScript включили «на всякий случай» — больше ошибок, курс его не требует.
