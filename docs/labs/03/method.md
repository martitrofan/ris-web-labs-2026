## 3. Коротко по делу
### 3.1. Vue и Vite
Vue связывает данные JavaScript с разметкой. Vite собирает `.vue`-файлы и запускает dev-сервер. Файл `App.vue` нельзя открыть двойным щелчком.
Однофайловый компонент:
```vue
<script setup>
// данные и функции
</script>
<template>
  <!-- разметка -->
</template>
<style scoped>
/* локальные стили */
</style>
```
### 3.2. Что нужно сегодня
- `ref` — реактивное значение;
- `v-if` / `v-else-if` — выбрать экран;
- `v-for` — повторить строку по массиву;
- `:key="item.id"` — дать строке устойчивый ключ;
- `{{ item.title }}` — безопасно вывести текст.
Не ставьте TypeScript, Pinia или axios: для результата ЛР3 они не нужны.
### 3.3. Семантика
`main`, `form`, `label`, `table` объясняют назначение элементов браузеру и человеку. Набор одинаковых `div` не заменяет эти элементы.

### Шаг D. Сделайте список
В `App.vue` заведите две тестовые записи:
```js
const items = [
  { id: 1, number: 'A-101', title: 'Насос не запускается', siteId: 2, status: 'New' },
  { id: 2, number: 'A-102', title: 'Проверить вентиль', siteId: 1, status: 'InProgress' }
```

Выведите их таблицей через `v-for`. Статусы используйте только из набора курса. Пользовательский текст выводите через двойные фигурные скобки, не через `v-html`.

### Шаг E. Сделайте форму создания

Форма пока только выглядит как будущая форма:

```html
<form @submit.prevent>
  <label for="title">Тема, 5–80 символов</label>
  <input id="title" name="title" autofocus>

  <label for="siteId">Номер справочника</label>
  <input id="siteId" name="siteId" type="number">

  <label for="description">Описание, 10–500 символов</label>
  <textarea id="description" name="description"></textarea>

  <button type="submit">Создать</button>
</form>
```

Имена `title`, `siteId`, `description` заменяйте только если в ЛР2 зафиксировали свои согласованные имена.

Экран входа содержит `form`, подпись логина, подпись пароля и кнопку. Настоящей авторизации ещё нет.

## 5. Частые косяки

| Ошибка | Как исправить |
|--------|---------------|
| Проект создан внутри `docs` | перенести `/frontend` в корень репозитория |
| Выбран TypeScript | пересоздать каркас на JavaScript до начала большой правки |
| `App.vue` открывают как HTML | запускать только через `npm run dev` |
| Все экраны сделаны из `div` | добавить `main`, `form`, `label`, `table` |
| Строки таблицы скопированы руками | использовать массив и `v-for` |
| Нет `:key` | добавить машинный `id` как ключ |
| Поля называются `name`, `place`, `text` | вернуть имена из API ЛР2 |
| В Git попал `node_modules` | удалить из индекса и добавить в `.gitignore` |
| Кнопка формы обновляет страницу | добавить `@submit.prevent` |
