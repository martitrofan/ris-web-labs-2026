# Шаблон: коллекция Postman / Insomnia

Скопируйте файл [`api-collection-postman.json`](api-collection-postman.json) в свой учебный репозиторий (например в `/docs/`) и импортируйте в Postman или Insomnia.

После импорта подставьте свой базовый URL сервера (обычно `http://localhost:5000`) и проверьте маршруты из ЛР8.
