## 3. Настройка frontend

### 3.1. Отключить mock

Рабочий режим:

```text
USE_MOCK=false
```

Если флаг задан через Vite:

```text
VITE_USE_MOCK=false
VITE_API_BASE_URL=http://localhost:5000
```

После изменения `.env` перезапустите `npm run dev`.
В Network должны появиться запросы на порт `5000`.

### 3.2. Порты

| Узел | Адрес |
|---|---|
| Vue | `http://localhost:5173` |
| ASP.NET Core | `http://localhost:5000` |
| PostgreSQL | локальный порт из настройки, обычно 5432 |

Не меняйте порты молча: README должен совпадать с фактическим запуском.

## 4. CORS

Разрешите на сервере конкретный origin:

```text
http://localhost:5173
```

Не ставьте `*` без понимания последствий.
Если используется cookie-вход, настройте credentials согласованно.

Признаки CORS-проблемы:

- запрос виден в Network, но браузер не отдаёт ответ приложению;
- Swagger на API работает;
- в консоли есть сообщение CORS;
- это не обычный ответ `500`.

## 5. Один id как доказательство

После создания запишите:

```text
id = ______ · number = ______
```

Проверьте тот же id:

| Где | Что показать |
|---|---|
| UI | строка или карточка с id/number |
| Network | POST 201 и id в Response |
| SQL | строка `WHERE id = ...` |
| после рестарта | GET возвращает ту же запись |

SQL:

```sql
SELECT id, number, title, status, assignee_user_id
FROM tickets
WHERE id = 17;
```

Не показывайте три разные записи: mock, Swagger seed и старую строку БД.
